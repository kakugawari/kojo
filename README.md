# ⚡🐱 ねこイライラ棒

ねこの輪っかを、カベに当てずにゴールまで運ぶゲーム。
素の HTML / CSS / JS だけ。ビルドなし。

```bash
npm start        # http://localhost:8080/
npm test         # ロジックのテスト
npm run test:ui  # ブラウザで実際に動かすテスト (要 npm i -D playwright)
```

- 画面を指で押すと、指の少し上に輪っかが出る（持っているのは棒）
- START の台に輪っかを入れると時計が動きだす
- カベ・じゃまものにさわる、指をはなす → その場でやり直し
- 6 ステージ。だんだん細く、じゃまものが増える

コースは「1 本の折れ線を太らせたもの」として持っているので、
見た目と当たり判定がズレず、クリアできないコースを作れない。
詳しくは [CLAUDE.md](./CLAUDE.md) に。
