# ⚡🏭 イライラ棒工場

イライラ棒を作っている工場の検査ライン。ラインを流れてくるユニットを、
テスト棒で 1 台ずつ通して合否を出す。
素の HTML / CSS / JS だけ。ビルドなし。

```bash
npm start        # http://localhost:8080/
npm test         # ロジックのテスト
npm run test:ui  # ブラウザで実際に動かすテスト (要 npm i -D playwright)
```

- 画面を指で押すと、指の少し上にリングが出る（にぎっているのは金属のテスト棒）
- START 端子にリングを入れると検査時間が動きだす
- 外わく・可動部にさわる、手をはなす → ショート、再検査
- 品番 IRB-01〜06 の 6 台。だんだんみぞが細く、可動部が増える
- 🔦 ボタンで**暗室検査**に切りかえ。手もとしか見えなくなる（形も判定も同じ）

みぞは「1 本の折れ線を太らせたもの」として持っているので、
見た目と当たり判定がズレず、通れないユニットを作れない。
詳しくは [CLAUDE.md](./CLAUDE.md) に。
