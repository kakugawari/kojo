# 🏭🐱 ねこ工場

かわいいねこたちが働く工場を、だんだん大きくしていく放置ゲーム。
素の HTML / CSS / JS だけ。ビルドなし。

```bash
npm start        # http://localhost:8080/
npm test         # ロジックのテスト
npm run test:ui  # ブラウザで実際に動かすテスト (要 npm i -D playwright)
```

- ねこをタップすると なでられる（そのぶんお金が入る）
- 指でなぞると工場が動く。2 本指でひろげると大きくなる。ダブルタップで全体表示
- 下のバーから 部署 / ねこ / ガチャ / じっせき

作り方と決めごとは [CLAUDE.md](./CLAUDE.md) に。
